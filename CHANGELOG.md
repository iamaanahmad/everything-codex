# Changelog

All notable changes to everything-codex are documented in this file.

## [Unreleased]

### Changed

- Reframed the repository as an adaptable template library rather than an installable Codex extension.
- Migrated repository contributor guidance from legacy `codex.md` to `AGENTS.md`.
- Updated README and installation guidance for current Codex usage across ChatGPT/cloud, CLI, IDE, GitHub, Skills, MCP/plugins, code review, and scheduled work.
- Removed obsolete CLI approval-mode, model, auto-loading, and static-pricing claims from active guidance.
- Added explicit least-privilege, review, validation, secret-handling, and automation safety guidance.
- Replaced the aging cross-product feature matrix with a durable, capability-oriented evaluation guide.
